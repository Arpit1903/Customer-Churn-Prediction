
# Customer Churn Prediction System

An end-to-end Machine Learning project that predicts:

1. Customer Churn (Classification)
2. Customer Lifetime Value / Monthly Charges (Regression)

This project is highly ATS-friendly and showcases practical business-oriented ML skills.

---

# Features

## Classification Models
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier

## Regression Models
- Linear Regression
- Random Forest Regressor

---

# Resume Description

Developed an end-to-end Customer Churn Prediction System using Python and Scikit-learn to predict customer churn and customer lifetime value. Implemented classification and regression models, feature engineering, hyperparameter tuning, and model evaluation using ROC-AUC, F1 Score, RMSE, and R² metrics.
